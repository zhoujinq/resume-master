## MVP 切片

1. **MVP-1｜验收内核**：先写失败测试；实现报告状态、源文覆盖、严格／建议／未做分离，保留旧 QA 调用。
2. **MVP-2｜Word 同源路线**：实现 YAML → DOCX → Word PDF，加入文本、链接、字体、照片检查；用虚构样例真实导出。
3. **MVP-3｜复现与交付**：第二次导出像素对比、视觉证据位、报告输出、Lite／README／项目页同步。
4. **发布门禁**：全量单元测试通过；本机 Word 端到端通过；真实 V53.1 只做本机验证、不进仓库；无隐私与密钥；推送后读取远程确认。

## 明确不做

- 不安装、卸载或转换用户字体，不修改注册表或 Word 全局选项。
- 不把 HTML／Chrome／Microsoft Print to PDF 称为 Word 同源导出。
- 不为凑页数静默删字、缩字号或改事实；语义变化仍返回全文确认。
- 不内置某一份简历的专用数字、公司、项目组合或本地路径。
- 不承诺 ATS 分数、面试、录用、薪资或 offer 概率。
