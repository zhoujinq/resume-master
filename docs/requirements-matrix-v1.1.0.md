# v1.1.0 需求依赖矩阵

目标：另一个用户把本 Skill 与自己的简历交给 Agent，即可得到优化版；附上目标岗位 JD 时，得到更匹配该岗位的版本。今天下午可交给朋友实测。

| ID | 用户价值 | 依赖 | 验收方式 | 切片 |
|---|---|---|---|---|
| R1 | 仅给简历也能优化，不强制补 JD | 输入读取 → 素材审计 → 内容重构 → 渲染 → QA | 契约测试＋无 JD 示例 | MVP-1 |
| R2 | 简历＋JD 时输出更匹配版本 | R1＋JD 要求抽取＋注入防御 | 契约测试＋JD 示例 | MVP-1 |
| R3 | 朋友可直接给 PDF / Word / Markdown / TXT / YAML | 各格式读取；扫描件和低置信度字段显式标注 | 输入契约测试 | MVP-1 |
| R4 | 不编造数字、不夸大归属，用户能在面试中解释 | 事实分层；归属词规则；集中确认 | 护栏测试 | MVP-1 |
| R5 | 默认少打断，不用四道路由菜单消耗用户 | 自动识别两种模式；只问影响成稿的问题 | 流程契约测试 | MVP-1 |

## MVP 切片

1. **MVP-1（先红后绿）**：两种模式、常见格式输入、少打断、事实与隐私底线。
2. **MVP-2**：标蓝清单、文案弹性、单一内容源、PDF／Word 真实渲染纪律。
3. **MVP-3**：匿名示例、朋友快速开始、现有渲染脚本 smoke、版本 v1.1.0。

不在本次扩张：自动投递、ATS 打分、招聘平台对接、面试题库、强制 DOCX 生成器。
