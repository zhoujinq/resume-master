# v3.2.0 需求依赖矩阵

目标：保留 v3.1.0 的证据、可选信息架构、固定视觉与 Word 同源生产内核，新增简历专用的去套话、改前改后事实对账和可选表达样本。优化对象是招聘判断所需的表达，不是 AI 检测器分数。

## 不可变量

1. 视觉保持思源宋体＋思源黑体、`#2F5BEA`；生产链保持结构化正文 → DOCX → Microsoft Word PDF。
2. 个人主页、GitHub、任何项目和照片均可省略；缺失不自动构成能力不足，配置后丢失仍必须失败。
3. 去套话不得改变事实、数字、归属、URL、事实 ID 或用户确认状态；需要改变这些内容时，退出纯润色并重新走证据确认。
4. 结构模式用于定位与解释，不把命中数当写作配额，不输出“人味百分比”“AI 概率”或录用预测。
5. 弱信号只提醒，不自动删改；真实对比、专业术语、日期范围、引用和用户确认原话可以保留。
6. 个人表达样本是可选输入；没有样本也能完成中性、专业的简历，绝不编造口头禅或个人习惯。
7. 公开仓库不包含真实简历数据、本机私有路径或生产证据；旧版本仅在 Git 历史中回滚。

## MVP 切片

1. **基线保留**：v3.1.0 全部 40 项回归继续通过，双候选人和真实 Word 门禁不回退。
2. **MVP-5｜写作门禁**：先写结构套话、误伤、对话残留、事实漂移和数字变化负样本，再实现内容审计与 `--baseline`。
3. **真实对照**：同一虚构输入比较改前改后；机械对账只证明字段与数字未变，语义等价由人工判断。真实 DOCX／Word PDF 继续验证生产链。
4. **发布**：同步全部入口、需求矩阵、反方评审、项目页与脱敏 QA；推送 main、v3.2.0 标签并线上核验。

## 明确路由出去

- 学术 CV、设计作品集、政府／联邦格式、复杂图表简历。
- ATS 打分、AI 检测器规避、人味百分比、自动投递、面试题库、录用或薪资预测。
- 把没有个人主页、GitHub、Vibe Coding 或照片解释为普遍能力短板。
- 为去套话而删除真实限制条件、归属、数字、专业术语或用户必须保留的原话。
- 未执行同题人工盲评却宣称新版本已经胜过旧版或通用 Humanizer。
