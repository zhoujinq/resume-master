# v3.0.0 需求依赖矩阵

目标：从“多模板简历生成器”重建为“证据驱动、单一视觉、Word 同源、负样本可证伪的中文简历工作流”。

## 不可变量

1. 只有一个视觉标准：思源宋体＋思源黑体；强调色 `#2F5BEA`。
2. 只有一条交付渲染链：结构化正文 → DOCX → Microsoft Word PDF。
3. 事实状态、归属、来源和用户确认优先于文案发挥。
4. 不为页数静默删字、缩字号、改项目顺序；不把未做写成通过。
5. 当前目录删除旧主题与旧渲染路线；旧版本仅通过 Git 历史回滚。
6. 公开仓库不包含真实简历数据、本机私有路径或生产证据。

## MVP 切片

1. **MVP-0｜反向契约**：先写单主题、单路线、固定字体与网站清理测试，让 v2 失败。
2. **MVP-1｜证据内核**：实现事实台账、数字／归属／确认校验、派生不降级；先用负样本证明有效。
3. **MVP-2｜V53.1 唯一生产链**：从实际封板路径抽象 DOCX，Word 导出，删除其他渲染器。
4. **MVP-3｜对账与红队**：全文、链接、字体、照片、行距、像素、编辑撤销、视觉证据和报告。
5. **发布**：虚构样例＋本机真实影子验收；同步 README、Lite、项目页、发布说明；推送并线上核验。

## 明确路由出去

- 学术 CV、设计作品集、政府／联邦格式、复杂图表简历。
- ATS 打分、自动投递、招聘平台对接、面试题库、录用或薪资预测。
- 无 Microsoft Word 时生成“替代引擎但冒充同源”的 PDF。
- 修改系统字体、注册表或 Word 全局设置。
