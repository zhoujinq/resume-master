# resume-master v2.0.0 发布说明

发布日期：2026-11-24

## 我做了什么

1. **新增 Word 同源路线**：同一份 YAML 生成可编辑 DOCX，正文不使用文本框；PDF 由 Microsoft Word 从同一 DOCX 导出，不用 HTML、浏览器或系统打印驱动冒充。
2. **把事实与排版连成一条验收链**：检查 YAML 源文覆盖、DOCX/PDF 归一化全文、真实超链接、页数、可见字符越界、字体、照片、文本层和文件体积。
3. **验收结论分层**：核心、严格、建议分别汇总；`NOT_RUN` 不计入通过，严格项未闭合时总体保持 `INCOMPLETE`。
4. **真实复现证据**：支持第二次 Word 导出后的同 DPI 逐页像素比较、逐页视觉证据、Word 实际编辑—撤销证据。
5. **保留原有能力**：全入口、集中问卷、两次确认、内容定稿后终排、HTML 三主题、ReportLab 兜底、Lite 与版本派生继续可用。
6. **文档同步**：重写 SKILL、README、交付／设计约束，更新 Lite 和项目介绍页；真实简历数据不进入公开仓库。

## 真实渲染抓出并修复的问题

- 章节 `body` 曾排到条目之后，现固定先于条目，并支持 `page_break_before`。
- 条目 `url` 曾未进入 DOCX，QA 也曾漏算这类链接；现渲染与验收都支持 `url`／`link`。
- 照片段落的固定行距会裁切图片，现照片段落使用单倍行距，只给显示宽度并等比缩放。
- Word 可能将间隔号／项目符号回映射为相近 Unicode；文本比较只规范化这类排版符号，不豁免文字或数字变化。
- PDF span 的尾随空格曾被误判为文字越界；现使用字符级可见边界，真实字母或数字越界仍失败。
- 完整中文字体曾令 PDF 超过 20MB；现只对 Word 已导出的 PDF 做无损字体子集化，不安装字体、不改注册表或 Word 全局设置。
