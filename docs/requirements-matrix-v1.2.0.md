| ID | 用户价值 | 依赖 | 验收方式 | 切片 |

## MVP 切片

1. **MVP-1**：先写失败测试，再打通全入口、集中问卷、缺失补问与结构线框确认。
2. **MVP-2**：同步完整正文确认、终排重检、脱敏案例、Lite 与项目文档。
3. **发布门禁**：全量测试通过、隐私扫描通过、远端差异只含本需求；不新增未验证的渲染脚本。

不在本次扩张：自动投递、ATS 打分、招聘平台对接、面试题库、强制 DOCX 生成器。
