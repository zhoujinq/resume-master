# 简历工坊 Pro v3.3.0

首个封板大版本之后，新增离线单文件微调工作台。

- 直接修改文字，Ctrl+B／按钮加粗，选中文字变色。
- 字号、行距、段后距按 0.1pt 调整，支持当前段／同类／全文。
- 本地自动保存、JSON 备份／恢复、副本版本号和封板原件下载。
- 最新 Word 以封板 DOCX 为模板原位更新；PDF 通过浏览器打印当前页面。
- HTML／浏览器 PDF 支持 0.1pt；DOCX 字号只能保存 0.5pt，取整会提示。
- 56 项 Python 测试与 13 项 Node 测试通过；真实 Microsoft Word 打开、编辑—撤销、6 个链接、照片、逐页视觉与重复导出像素差 0 均通过。
- 浏览器打印入口已实测；原生系统保存对话框未自动操作，浏览器 PDF 文件级保存如实标记 NOT_RUN。

公开样例全部为虚构内容。
