# v3.3.0 设计论证：封板之后，把最后 5% 交还给候选人

## 1. 第一性原理

简历生产有两个不同目标。封板前追求“内容真实、结构稳定、可验收”；封板后追求“本人能快速改几个字、强调一处成果、微调呼吸感，并立即带走最新版”。把这两个目标塞进同一个自由编辑器，会让排版便利反向破坏事实与版式基线。

因此本版不是第二条初始生产链，而是**封板后的派生微调层**：先完成第一个封板大版本，再生成编辑器。原始 YAML、DOCX、PDF 和 QA 保持不变，编辑器保存个人后续修订。

## 2. 为什么不能直接从 PDF 反向猜 HTML

PDF 主要记录绘制位置，不天然保存可靠的段落、条目与阅读顺序。直接按坐标切片，容易把一行切成多个伪段落、弄错日期归属、破坏链接或照片。只有 PDF 的外部简历应先抽取文字并由用户确认结构。

本 Skill 已拥有最终 YAML 和封板 DOCX，所以采用“最终 PDF 验证可见内容＋最终 YAML 提供语义结构＋封板 DOCX 提供原位导出模板”的方式。生成器检查 PDF 存在、QA 无核心／严格阻断、PDF／DOCX 内容覆盖和段落映射，并记录三份文件的 SHA-256。这样编辑器确实基于封板内容，又不靠 OCR 猜结构或另起一套 Word 版式。

## 3. 跨领域映射

| 领域 | 可复用机制 | 本版对应 |
|---|---|---|
| 数据库迁移 | 生产模式与后续补丁分开，记录基版本 | 封板 YAML／PDF／DOCX 三哈希＋派生编辑状态 |
| 本地优先软件 | 数据先归用户，离线可用，显式备份 | 单文件 HTML、localStorage、JSON 导入导出 |
| 富文本编辑器 | 选区命令与块级样式是两类操作 | Ctrl+B／文字色作用于选区，字号／行距作用于段落范围 |
| 排版预检 | 输出前检查介质精度与溢出 | DOCX 0.5pt 提示、A4 分页与可能增页提示 |
| 财务改动对账 | 自动检查异常，但不替代责任人确认 | 数字词元变化 WARN，用户仍可自主导出 |
| 可复现构建 | 模板、依赖与数据固化 | 构建时内联 JSZip 与简历数据，运行时不依赖 CDN |

## 4. 导出架构

- **Word**：读取当前 DOM 并序列化为编辑状态，用内联 JSZip 打开原封板 DOCX，在段落一一对应的前提下原位更新文字 Run、粗体、颜色、超链接与排版参数。页边距、编号、图片和未修改部件沿用封板文件；错配即停止，不静默换成另一套 OOXML。
- **PDF**：使用浏览器打印当前页面，打印样式只保留 A4 简历。用户选择“另存为 PDF”；静态网页不伪称有服务器或直接文件写入权限。
- **数据**：备份 JSON 保存文字、局部格式、段落样式、强调色与基版本哈希，便于换设备与恢复。

HTML／PDF 支持 0.1pt。DOCX 的 `w:sz` 是半磅整数，因此字号只能取最近 0.5pt；行距与段距使用 twips，可表达 0.05pt 精度。导出 UI 与文档都披露这一介质差异。

## 5. 最强反对者审查

| 反对证据／边界 | 重新评估后的处理 |
|---|---|
| HTML 会成为第二条失控排版链 | 只允许在封板后派生；封板前仍走唯一 DOCX→Word PDF |
| PDF 反读会破坏阅读顺序 | 不直接猜 PDF 结构；使用经 PDF 覆盖验证的最终 YAML |
| contenteditable 会引入脏 HTML 或脚本 | 输入与备份统一消毒，只允许有限标记；无运行时外部请求 |
| 浏览器打印并不是“直接下载 PDF” | 按钮明确写“打印／另存为 PDF”，不虚构服务器能力 |
| DOCX 无法保存 0.1pt 字号 | 明示 0.5pt 取整；HTML／PDF 保留 0.1pt |
| 用户改数字可能破坏事实 | 提示复核但不越权锁死；机械检查不声称语义真实 |
| localStorage 清理后丢稿 | 提供 JSON 备份／恢复与重置封板原版 |
| 增大字号或行距会增页 | 页面可扩展并提示可能增页，不隐藏溢出或裁切 |
| 不同浏览器与 Word 渲染不完全一致 | 只承诺当前内容进入导出，不承诺跨引擎逐像素一致；用真实 Word 验收 |
| 照片与链接在导出时可能丢失 | OOXML 关系、图片部件和真实 Word 打开测试，而非只测文本 |
| 公共在线编辑器会泄露简历 | 示例只含虚构数据；生成器产出本地单文件，编辑与导出均在浏览器完成 |

## 6. 最终判断

本版最本质的变化不是“多一个网页”，而是把生命周期切开：AI 对封板前的证据、内容和首个版式负责；候选人对封板后的微小修订拥有直接控制权。自由被放在正确的阶段，边界、精度与风险都说清楚，才能既方便自己改，又不重做一遍简历生产系统。
